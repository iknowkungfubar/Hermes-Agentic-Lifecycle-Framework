# 02_wiki — Codified Knowledge

**Purpose:** Architecture records, domain invariants, schema specifications.

This is the curated knowledge layer containing:
- Architectural Decision Records (ADRs)
- Domain models and invariants
- API schema specifications
- Database schema documentation
- System architecture diagrams
- Coding conventions and patterns

## Conventions

- Markdown files with Mermaid diagrams
- Every file has a metadata header (tags, status, last-reviewed)
- Cross-references use Obsidian `[[wiki-links]]`
- Status indicators: `draft → review → published → deprecated`
