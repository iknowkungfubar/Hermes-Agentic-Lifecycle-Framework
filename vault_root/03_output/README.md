# 03_output — Validated Reports

**Purpose:** Finalized code components, validated structural reports.

This is the output layer containing:
- Merge-Readiness Packs (MRPs) ready for human review

## Conventions

- Files are immutable once written (read-only after validation)
- SHA-256 checksums recorded in metadata
- Sign-off status tracked in frontmatter
- Cross-reference to the git commit SHA
