# 01_raw — Staging Ground

**Purpose:** Unverified logs, meeting transcripts, raw output dumps.

This is the initial landing zone for:
- Raw agent execution logs before processing
- Meeting transcripts (voice-to-text dumps from Whisper.cpp)
- Unverified build outputs
- Scratch notes and provisional documentation

## Conventions

- Files are named with ISO date prefix: `YYYY-MM-DD_description.md`
- No guarantee of correctness — this is the "working memory"
- Processed/digested content moves to `02_wiki/`
- Content older than 30 days is auto-archived
