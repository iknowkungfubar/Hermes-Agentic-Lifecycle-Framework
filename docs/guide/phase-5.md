# Phase 5: Iteration

**Objective:** Continuous improvement through feedback loops, issue triage, and codification.

## Steps

- **5A: Production Monitoring** — Metric collection (15m), log analysis (1h), anomaly detection
- **5B: Issue Triage** — Classify (bug/feature/debt/incident), reproduce, fix, PR
- **5C: Codification Imperative** — Every manual fix → durable system improvement
- **5D: QoL Updates** — Weekly dependency check, coverage trend, spec drift detection

## Codification Imperative

When a human corrects an agent action:
1. WHAT was the correction?
2. WHY was the agent wrong?
3. HOW can the agent avoid this next time?

The answer becomes: AGENTS.md update, skill update, HALF workflow update, or test case.

## Gate Check (G5)

- G5.1: Monitoring loop is active
- G5.2: Issue triage workflow documented
- G5.3: No HIGH/CRITICAL issues unresolved >7 days
- G5.4: Codification Imperative is active
